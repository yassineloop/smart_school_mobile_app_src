# Run Instructions for Client

To run this Flutter project on your local machine, please follow these simple steps:

### Prerequisites
1.  **Flutter SDK**: Ensure you have Flutter installed. [Click here for installation guide](https://docs.flutter.dev/get-started/install).
2.  **Environment**: You will need a physical device or emulator (Android/iOS) connected.

### Setup and Run
1.  Open your terminal or command prompt in this project folder.
2.  Run the following command to download all necessary dependencies:
    ```bash
    flutter pub get
    ```
3.  Run the application on your connected device:
    ```bash
    flutter run
    ```

---
*Note: I have cleaned the project's build caches and temporary files to keep the shared file size minimal. Flutter will automatically rebuild these files during the first run.*
